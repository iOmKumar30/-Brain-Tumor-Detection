# Changelog

## 0.1.0

- Refactored notebook-only project into a package-based ML application.
- Added typed YAML configuration.
- Added PyTorch 3D UNet baseline.
- Added MONAI UNETR and SwinUNETR model builders.
- Added deterministic training, AMP, gradient accumulation, checkpointing, early stopping, and scheduler support.
- Added multiclass-safe segmentation metrics.
- Added inference predictor and CLI.
- Added FastAPI backend.
- Added React/TypeScript web interface.
- Added Docker and docker-compose.
- Added dataset, architecture, deployment, audit, and benchmark documentation.
- Added test scaffolding.
